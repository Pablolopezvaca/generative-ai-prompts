# Generative AI Prompting Guide

Este repositorio contiene una colección de prácticas recomendadas, ejemplos y técnicas para trabajar con modelos generativos de inteligencia artificial, como los de Google Gemini, Claude o OpenAI. La información está dividida en tres bloques temáticos.

## 📄 Archivos incluidos

1. **01-prompt-engineering-best-practices.md**  
   Buenas prácticas para redactar prompts eficaces, concisos y seguros para tareas generativas o clasificatorias.

2. **02-ideation.md**  
   Técnicas de ideación con IA generativa, incluyendo generación de nombres, campañas de marketing, memes, entrevistas, etc.

3. **03-question-answering.md**  
   Métodos para formular preguntas a modelos generativos en dominios abiertos y cerrados, incluyendo evaluación de respuestas.

## 🧠 ¿Por qué este repositorio?

Este material puede servir como referencia para:
- Estudiantes de IA y NLP
- Profesionales que trabajan con modelos LLM
- Equipos de producto y UX que diseñan experiencias conversacionales

## 🚀 Cómo usarlo

Puedes clonar este repositorio o simplemente consultar los archivos Markdown según el tema de interés. Si deseas experimentar con estos ejemplos, puedes usarlos directamente en interfaces como ChatGPT o en entornos de prueba de Gemini o Claude.

## 📚 Créditos

Basado en materiales educativos y mejores prácticas ampliamente compartidas por comunidades de IA generativa.
